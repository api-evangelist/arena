# Arena

> Arena is an AI-powered audience engagement platform that lets publishers and brands build communities on their own websites with real-time Live Chat, Live Blog, Comments, Polls, and Q&A. Developers integrate via the Arena Platform API and official JavaScript, Android, and iOS SDKs, authenticating with an API key or a JWT (which also powers SSO). Backed by CRV, Felicis, Lightspeed Venture Partners, and Techstars.

## Products & APIs
- [Arena Platform API (V3)](https://developers.arena.im/): REST API covering Liveblog, Live Chat, Analytics, Account, Stream, Users, Moderation, Polls, and Q&A.
- [Arena Chat SDK](https://www.npmjs.com/package/@arena-im/chat-sdk): Official JavaScript client for Arena Live Chat.
- [Arena Liveblog SDK](https://www.npmjs.com/package/@arena-im/liveblog-sdk): Official JavaScript client for Arena Live Blog.
